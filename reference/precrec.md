# precrec: A package for computing accurate ROC and Precision-Recall curves

The precrec package contains several functions and `S3` generics to
provide a robust platform for performance evaluation of binary
classifiers.

## Functions

The precrec package provides the following six functions.

|  |  |
|----|----|
| **Function** | **Description** |
| [`evalmod()`](https://evalclass.github.io/precrec/reference/evalmod.md) | Main function to calculate evaluation measures |
| [`mmdata()`](https://evalclass.github.io/precrec/reference/mmdata.md) | Reformat input data for performance evaluation calculation |
| [`join_scores()`](https://evalclass.github.io/precrec/reference/join_scores.md) | Join scores of multiple models into a list |
| [`join_labels()`](https://evalclass.github.io/precrec/reference/join_labels.md) | Join observed labels of multiple test datasets into a list |
| [`create_sim_samples()`](https://evalclass.github.io/precrec/reference/create_sim_samples.md) | Create random samples for simulations |
| [`format_nfold()`](https://evalclass.github.io/precrec/reference/format_nfold.md) | Create n-fold cross validation dataset from data frame |

## S3 generics

The precrec package provides nine different `S3` generics for the `S3`
objects generated by the
[`evalmod()`](https://evalclass.github.io/precrec/reference/evalmod.md)
function.

|  |  |  |
|----|----|----|
| **S3 generic** | **Library** | **Description** |
| `print` | base | Print the calculation results and the summary of the test data |
| [`as.data.frame()`](https://evalclass.github.io/precrec/reference/as.data.frame.md) | base | Convert a precrec object to a data frame |
| [`plot()`](https://evalclass.github.io/precrec/reference/plot.md) | graphics | Plot performance evaluation measures |
| [`autoplot()`](https://evalclass.github.io/precrec/reference/autoplot.md) | ggplot2 | Plot performance evaluation measures with ggplot2 |
| [`fortify()`](https://evalclass.github.io/precrec/reference/fortify.md) | ggplot2 | Prepare a data frame for ggplot2 |
| [`auc()`](https://evalclass.github.io/precrec/reference/auc.md) | precrec | Make a data frame with AUC scores |
| [`part()`](https://evalclass.github.io/precrec/reference/part.md) | precrec | Calculate partial curves and partial AUC scores |
| [`pauc()`](https://evalclass.github.io/precrec/reference/pauc.md) | precrec | Make a data frame with pAUC scores |
| [`auc_ci()`](https://evalclass.github.io/precrec/reference/auc_ci.md) | precrec | Calculate confidence intervals of AUC scores |

## Performance measure calculations

The
[`evalmod()`](https://evalclass.github.io/precrec/reference/evalmod.md)
function calculates ROC and Precision-Recall curves and returns an `S3`
object. The generated `S3` object can be used with several different
`S3` generics, such as `print` and
[`plot()`](https://evalclass.github.io/precrec/reference/plot.md). The
[`evalmod()`](https://evalclass.github.io/precrec/reference/evalmod.md)
function can also calculate basic evaluation measures - error rate,
accuracy, specificity, sensitivity, precision, Matthews correlation
coefficient, F-score, balanced accuracy, negative predictive value,
informedness, markedness, and Cohen's kappa.

## Data preparation

The
[`mmdata()`](https://evalclass.github.io/precrec/reference/mmdata.md)
function creates an input dataset for the
[`evalmod()`](https://evalclass.github.io/precrec/reference/evalmod.md)
function. The generated dataset contains formatted scores and labels.

[`join_scores()`](https://evalclass.github.io/precrec/reference/join_scores.md)
and
[`join_labels()`](https://evalclass.github.io/precrec/reference/join_labels.md)
are helper functions to combine multiple scores and labels.

The
[`create_sim_samples()`](https://evalclass.github.io/precrec/reference/create_sim_samples.md)
function creates test datasets with five different performance levels.

## Data visualization

[`plot()`](https://evalclass.github.io/precrec/reference/plot.md) takes
an `S3` object generated by
[`evalmod()`](https://evalclass.github.io/precrec/reference/evalmod.md)
as input and plot corresponding curves.

[`autoplot()`](https://evalclass.github.io/precrec/reference/autoplot.md)
uses `ggplot` to plot curves.

## Result retrieval

[`as.data.frame()`](https://evalclass.github.io/precrec/reference/as.data.frame.md)
takes an `S3` object generated by
[`evalmod()`](https://evalclass.github.io/precrec/reference/evalmod.md)
as input and and returns a data frame with calculated curve points.

[`auc()`](https://evalclass.github.io/precrec/reference/auc.md) and
[`pauc()`](https://evalclass.github.io/precrec/reference/pauc.md)
returns a data frame with AUC scores and partial AUC scores,
respectively.
[`auc_ci()`](https://evalclass.github.io/precrec/reference/auc_ci.md)
returns confidence intervals of AUCs for both ROC and precision-recall
curves.

[`average_precision()`](https://evalclass.github.io/precrec/reference/average_precision.md)
returns the step estimator of the area under the precision-recall curve,
and [`prbe()`](https://evalclass.github.io/precrec/reference/prbe.md)
the precision-recall break-even point.

## Probability-based measures

[`prob_metrics()`](https://evalclass.github.io/precrec/reference/prob_metrics.md)
calculates the Brier score and the log loss of prediction scores that
are probabilities, and
[`prob_metrics_ci()`](https://evalclass.github.io/precrec/reference/prob_metrics_ci.md)
returns their confidence intervals over multiple test datasets.
